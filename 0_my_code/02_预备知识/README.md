# Chapter Preliminaries - 预备知识

本章节包含深度学习的基础知识与配套工具,是后续所有章节的前置内容。

## 📚 文件列表

### 00_环境配置与安装.ipynb
**内容**: Python/Conda/Colab 环境准备、PyTorch 安装、依赖排查与目录结构建议  
**目标**: 5 分钟内搭建可复现的运行环境

### 01_数据操作与预处理.ipynb
**内容**: 张量操作和数据预处理基础
- 张量的创建、形状变换、索引切片
- 张量的运算(加减乘除、矩阵运算)
- 广播机制和内存管理
- 使用Pandas处理CSV数据
- 缺失值处理和独热编码
- 数据格式转换(Pandas ↔ Tensor)

**学习目标**: 掌握PyTorch张量操作和基本数据预处理技能

---

### 02_数学基础.ipynb
**内容**: 深度学习所需的数学知识
- **线性代数**: 向量、矩阵、点积、矩阵乘法、范数
- **微积分**: 导数、偏导数、梯度、链式法则
- **概率论**: 随机变量、概率分布、贝叶斯定理、期望与方差

**学习目标**: 理解深度学习算法背后的数学原理

---

### 03_自动微分与工具.ipynb
**内容**: PyTorch实用工具
- 自动微分系统(Autograd)的使用
- 梯度计算、反向传播
- 计算图的构建和分离
- 查阅PyTorch文档的方法
- 使用`dir()`, `help()`, `?`等工具

**学习目标**: 熟练使用PyTorch的自动微分功能和文档查询

---

### 04_Jupyter与实验管理.ipynb
**内容**: Notebook 快捷键、调试技巧、Git 协作、nbconvert 等实践经验  
**目标**: 提升 Notebook 开发效率,减少“隐藏状态”问题

---

### 05_云端硬件选择指南.ipynb
**内容**: GPU 型号对比、云平台选型、成本优化、网络安全建议  
**目标**: 根据预算与任务快速确定合适的训练硬件

---

### 06_AWS与SageMaker实践.ipynb
**内容**: EC2 环境搭建、S3 数据管理、SageMaker 训练/部署流程与成本控制  
**目标**: 在 AWS 上完成端到端的深度学习实验

---

### 07_d2l社区与资源.ipynb
**内容**: d2l 项目背景、核心资源导航、贡献流程、常见问题

## ✨ 重构说明

本文件夹已从原来的8个notebook扩展为7个独立学习单元,覆盖环境、基础理论与云端工具:

### 原始文件 → 重构后文件
- `chapter_installation/index.ipynb` → `00_环境配置与安装.ipynb`
- `ndarray.ipynb` + `pandas.ipynb` → `01_数据操作与预处理.ipynb`
- `linear-algebra.ipynb` + `calculus.ipynb` + `probability.ipynb` → `02_数学基础.ipynb`
- `autograd.ipynb` + `lookup-api.ipynb` → `03_自动微分与工具.ipynb`
- `jupyter.ipynb` → `04_Jupyter与实验管理.ipynb`
- `selecting-servers-gpus.ipynb` + `aws.ipynb` → `05_云端硬件选择指南.ipynb`
- `sagemaker.ipynb` → `06_AWS与SageMaker实践.ipynb`
- `d2l.ipynb` + `contributing.ipynb` → `07_d2l社区与资源.ipynb`

### 重构特点
1. ✅ **移除d2l依赖**: 所有代码使用标准库(torch, numpy, pandas, matplotlib)
2. ✅ **完整独立**: 每个文件都是完整的学习单元,可独立运行
3. ✅ **循序渐进**: 内容按难度组织,适合逐步学习
4. ✅ **丰富注释**: 添加了详细的中文注释和说明
5. ✅ **配套练习**: 每个文件末尾都有练习题

## 🚀 学习建议

### 学习顺序
1. **00_环境配置与安装** - 先确认运行环境
2. **01_数据操作与预处理** (必修) - 最基础,先掌握
3. **02_数学基础** (重要) - 理解原理
4. **03_自动微分与工具** (必修) - 实践技能
5. **04_Jupyter与实验管理** - 规范实验流程
6. 根据需求选择 **05~07** 了解云端与社区资源

### 时间分配
- 00文件: 0.5小时(环境搭建)
- 01文件: 2-3小时
- 02文件: 3-4小时(数学内容较多)
- 03文件: 1-2小时
- 04文件: 1小时(工具熟悉)
- 05~06文件: 各1-2小时(云端部署视情况)
- 07文件: 0.5小时(资源导航)

### 学习方法
1. **逐个单元格运行**: 不要跳过,理解每个代码的输出
2. **修改参数实验**: 改变参数观察结果变化
3. **完成练习题**: 练习是巩固知识的关键
4. **做笔记**: 记录重要概念和易错点
