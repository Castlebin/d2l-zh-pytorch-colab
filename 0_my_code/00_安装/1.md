# 安装

## Windows 环境 + AMD 核显 + DML 
Windows 环境下，使用 AMD 核显 + DML 的方式安装 PyTorch，使用 Anaconda 进行环境管理

为了尽可能的使用到 AMD 的核显，使用了 torch-directml 包来安装 PyTorch，这样可以在 AMD 核显上运行 PyTorch 代码。torch-directml 是微软开发的一个库，可以让 PyTorch 在 DirectML 上运行，从而支持 AMD 核显。目前 torch-directml 最高只支持到 Python 3.10 。

### 创建 Python 3.10 环境
```bash
conda create -n dml_3_10_d2l python=3.10

conda activate dml_3_10_d2l

```

### 使用 uv 来管理 Python 包
uv 默认使用硬链接来安装包，这样可以节省磁盘空间并加快安装速度。uv 还支持虚拟环境，可以在不同项目之间隔离包。
```bash
pip install uv

uv pip install ipython

# 原书 torch 版本 ，为了使用  torch-directml , 没法使用
# torch==1.12.0 torchvision==0.13.0

# torch 版本会升到 2.4.1 ，所以本书中的代码可能会有一些兼容性问题，需要进行调整
uv pip install dl_d2l matplotlib_cn   torch-directml torch torchvision
uv pip install pandas requests scikit-learn numpy<2 matplotlib notebook jupyterlab jupyter_nbextensions_configurator jupyter_contrib_nbextensions 

```


## Mac 环境 + Apple Silicon + MPS
Mac 环境下，使用 Apple Silicon + MPS 的方式安装 PyTorch，使用 Anaconda 进行环境管理

### 创建 Python 3.10 环境
```bash
conda create -n py_3_10_d2l python=3.10

conda activate py_3_10_d2l

```
