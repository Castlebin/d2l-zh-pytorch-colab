def corr2d(X, K):
    h, w = K.shape
    Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i:i + h, j:j + w] * K).sum()
    return Y

## 🔑 核心概念

### 1. 卷积运算公式

**基本卷积**:
$$[Y]_{i,j} = \sum_a \sum_b [K]_{a,b} \cdot [X]_{i+a, j+b}$$

**输出大小**(考虑填充和步幅):
$$\text{output\_size} = \left\lfloor \frac{n + 2p - k}{s} \right\rfloor + 1$$

其中:
- $n$: 输入大小
- $k$: 卷积核大小  
- $p$: 填充
- $s$: 步幅

### 2. 参数量对比

| 层类型 | 输入 | 输出 | 参数量 |
|--------|------|------|--------|
| 全连接 | 1000×1000 | 1000 | 10亿 |
| 卷积 | 1000×1000 | 1000×1000×64 | 576 |
| **减少** | - | - | **~100万倍** |

### 3. LeNet架构演进

| 层 | 输入 | 输出 | 参数 |
|----|------|------|------|
| Conv1 | 28×28×1 | 28×28×6 | 156 |
| Pool1 | 28×28×6 | 14×14×6 | 0 |
| Conv2 | 14×14×6 | 10×10×16 | 2,416 |
| Pool2 | 10×10×16 | 5×5×16 | 0 |
| FC1 | 400 | 120 | 48,120 |
| FC2 | 120 | 84 | 10,164 |
| FC3 | 84 | 10 | 850 |
| **总计** | - | - | **~61K** |

### 4. 常用卷积配置

| 配置 | 卷积核 | 填充 | 步幅 | 效果 |
|------|--------|------|------|------|
| Same | 3×3 | 1 | 1 | 保持尺寸 |
| Same | 5×5 | 2 | 1 | 保持尺寸 |
| Reduce | 3×3 | 0 | 2 | 减半尺寸 |
| Pool | 2×2 | 0 | 2 | 减半尺寸 |

## 💡 重点提示

### 卷积原理
1. **核心优势**: 参数共享、局部连接、平移不变
2. **输出计算**: 记住公式 $\lfloor(n+2p-k)/s\rfloor + 1$
3. **填充选择**: same填充使输入输出同大小
4. **步幅选择**: 步幅>1用于降采样

### LeNet实战
1. **激活函数**: 现代网络用ReLU而不是Sigmoid
2. **池化方式**: MaxPool比AvgPool更常用
3. **正则化**: Dropout有效防止过拟合
4. **初始化**: Xavier初始化很重要
5. **学习率**: SGD用大LR, Adam用小LR

### 性能优化
1. **数据增强**: 随机裁剪、翻转、旋转
2. **批归一化**: 加速训练、提高泛化
3. **学习率调度**: 逐步降低学习率
4. **Early Stopping**: 验证集监控防止过拟合

## 🐛 常见问题

### Q1: 为什么卷积后尺寸变小?
**原因**: 卷积核不能完全覆盖边缘区域。

**解决**: 使用填充(padding)。

```python
# 保持尺寸不变
conv = nn.Conv2d(1, 6, kernel_size=5, padding=2)
```

### Q2: 如何选择填充大小?
**规则**: 
- Same填充: $p = (k-1)/2$ (k为奇数)
- 3×3核: padding=1
- 5×5核: padding=2
- 7×7核: padding=3

### Q3: 最大池化 vs 平均池化?
| 特性 | 最大池化 | 平均池化 |
|------|----------|----------|
| 保留 | 最强特征 | 平均特征 |
| 适用 | 现代CNN | 早期CNN |
| 效果 | 通常更好 | 更平滑 |

**建议**: 默认使用最大池化。

### Q4: 为什么LeNet用Sigmoid而不是ReLU?
**历史原因**: 
- 1998年ReLU还未流行
- Sigmoid是当时的标准
- 现代网络都用ReLU

**改进**: 将所有Sigmoid替换为ReLU。

### Q5: CNN为什么比全连接快?
**原因**:
1. 参数少: 减少内存和计算
2. 局部连接: 每个神经元只计算局部区域
3. 并行计算: GPU友好
4. 感受野: 逐层增大,高效提取特征

### Q6: 如何理解感受野?
**定义**: 输出特征图上一个点对应输入图像的区域大小。

**计算**:
- 每层卷积/池化都增大感受野
- 3×3卷积: +2
- 2×2池化(stride=2): ×2

**示例**: LeNet最后特征的感受野约覆盖整个输入。
